# 抚州仲裁委员会就申请人对被申请人买卖合同纠纷进行仲裁案

抚州仲裁委员会就申请人对被申请人买卖合同纠纷进行仲裁案

## 案情简介

申请人 A 公司与被申请人 B 公司签订《桁架采购合同》。合同约定了货到票到月结30天，付款方式为网银现金转账。合同签订后，申请人根据 B 公司订单发货。2021年7月5日，A公司与 B 公司对账，货款为人民币347337.04元，后被申请人B 公司仅支付货款人民币10万元。申请人遂向本会申请仲裁，要求 B 公司支付欠付货款247337.04元及利息，而 B 公司为一人有限责任公司，其唯一股东为 C 公司，根据公司法及其司法解释的规定，一人有限责任公司的股东不能证明公司财产独立于股东自己财产的，应对一人有限责任公司的债务应承担连带责任。

B 公司答辩称，欠款属实，利息不应当支付。

C 公司辩称，本案与 C 公司无关，C 公司不是本案合同相对方，不应当承担责任。

## 争议焦点

1、支付货款247337.04元的逾期利息是否有事实和法律依据；

2、C 公司是否应当对 B 公司的债务承担连带清偿责任。

仲裁庭经审理，提出裁决意见如下：

1、关于 B 公司的欠款数额,根据案涉应收款对账单，双方确认为人民币247337.04元，仲裁庭对 A 公司该项请求予以支持；

2、关于逾期利息。根据《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》（法释〔2020〕17号修改的司法解释之一）第十八条第四款“买卖合同没有约定逾期付款违约金或者该违约金的计算方法，出卖人以买受人违约为由主张赔偿逾期付款损失，违约行为发生在2019年8月19日之前的，人民法院可以中国人民银行同期同类人民币贷款基准利率为基础，参照逾期罚息利率标准计算；违约行为发生在2019年8月20日之后的，人民法院可以违约行为发生时中国人民银行授权全国银行间同业拆借中心公布的一年期贷款市场报价利率（LPR）标准为基础，加计30—50%计算逾期付款损失。 ”之规定，仲裁庭认为，申请人 A 公司要求 B 公司按中国人民银行同期同类贷款利率计算支付逾期利息的请求有法律依据，应当予以支持；

3、关于 C 公司是否承担连带责任。A 公司主张被 B 公司与 C公司之间存在人格混同的事实，应由 C 公司举证证明其法人财产独立于 B 公司法人财产，但 C 公司并未向仲裁庭提供证据证明其法人财产独立于被申请人 B 公司财产的事实，应承担举证不能的法律后果。因此，C 公司对被申 B 公司的债务应承担连带责任。

## 裁决结果

1、B 公司于本裁决送达之日起十日内向 A 公司支付货款247337.04元及利息（自2021年8月4日起至2021年10月31日利息2295.83元，2021年11月1日起以247337.04元为基数按全国银行间同行业拆借中心公布的贷款市场报价利率计至实际清偿完毕之日止）；

2、C 公司对 B 公司的上述债务承担连带责任。

## 相关法律法规解读

《公司法》第六十三条规定：“一人有限责任公司的股东不能证明公司财产独立于股东自己财产的，应当对公司债务承担连带责任。”我国公司法在一人有限责任公司的法人人格否认方面采取了举证责任倒置的举证原则，一人有限责任公司股东应当就其自身财产独立于公司财产承担举证责任。

## 结语和建议

根据《中华人民共和国公司法》第二章第三节规定，一人有限责任公司，是指只有一个自然人股东或者一个法人股东的有限责任公司：(一)一人有限责任公司出资主体是单一的，一个自然人只能投资设立一个一人有限责任公司。该一人有限责任公司不能投资设立新的一人有限责任公司;(二)一人有限责任公司的注册资本最低限额为人民币十万元。股东应当一次足额缴纳公司章程规定的出资额;(三)一人有限责任公司不设股东会;(四)一人有限责任公司应当在每一会计年度终了时编制财务会计报告，并经会计师事务所审计;(五)一人有限责任公司的股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任。因此，一人有限责任公司的设立及经营管理应当遵循上述五项规定，本案中 B 公司对欠付货款的金额无异议，仲裁庭予以了确认。

C 公司在审理中，不能提交一人有限责任公司年度审计报告及其他相关证据证明公司财产独立性，仲裁庭据此裁决 C 公司应当承担连带责任于法有据，裁决结果合法合理。

另，本案中，A 公司与 B 公司签订了买卖合同，C 公司作为连带责任人未在合同上签字盖章，是否应当受仲裁协议的约束，庭审中，仲裁庭经明示，C 公司明示愿意接受本会管辖，本案仲裁庭在程序上作了充分考虑，有力的保证了仲裁裁决的公信力。
