# 巴彦淖尔仲裁委员会就申请人某建设公司对被申请人某公司、第三人某公司建设工程施工合同纠纷进行仲裁案

巴彦淖尔仲裁委员会就申请人某建设公司对被申请人某公司、第三人某公司建设工程施工合同纠纷进行仲裁案

## 案情简介

2011年8月29日，仲裁本请求申请人 A 建设公司与被申请人B 公司、被申请人 D 地产公司签订《建设工程施工合同》，由申请人 A 建设公司对被申请人 B 公司投资建设的 XXXX 物流园一期工程进行施工总承包，工程施工内容为办公楼、宿舍楼、1#2#4#5#6#8#11#12#综合楼共计53289 ㎡。

2013年4月15日申请人 A 建设公司与被申请人 B 公司签订《建设工程施工合同》，由申请人 A 建设公司对 XXXX 物流园续建工程进行施工总承包，工程施工内容为封闭大厅、花卉市场、冷库（设备）、仓库、大棚、公厕、泵房、垃圾转运站共计12060.03 ㎡。

合同签订后，申请人 A 建设公司按合同约定进行施工，并于2013年10月18日将2#12#楼进行了竣工备案并交付被申请人B 公司使用；2015年9月23日将4#5#6#11#楼进行了竣工备案并交付 B 公司使用，2017年5月3日将封闭大厅、花卉市场、冷库（设备）、仓库、大棚、公厕、泵房、垃圾转运站进行了竣工备案并交付 B 公司使用。

2017年1月5日被申请人 B 公司出具《B 公司关于解决 A 公司工程问题专题会会议纪要》（2017）1号文件，2017年1月11日B 公司出具《B 公司工程问题处理意见沟通会会议纪要》（2017）4号文件，均对结欠 A 公司工程款进行了阐述。2013年由B 公司提交 XXXXX 工程造价咨询有限责任公司进行了最终工程造价审计，审计工程总造价为152178075元。

2018年4月18日由被申请人 B 公司、C 公司、申请人 A 建设公司及 XXXXX 会计事务所对案涉项目进行了协商，并由B 公司出具了《B 公司关于协调处理 A 建设公司工程款的专题会议纪要》（2018）3号文件，文件中体现扣除1#8#楼未完工程款等，尚结欠 A 建设公司工程款6895863.33元。

2019年1月31日，被申请人 B 公司的全资股东 C 公司给申请人A 建设公司出具《承诺函》，承诺保证结欠 A 建设公司的工程款B 公司进行给付，案涉两份《建设工程施工合同》均约定有仲裁条款。

基于以上事实，申请人 A 建设公司将 B 公司、C 公司列为被申请人、D 地产公司列为第三人向巴彦淖尔仲裁委员会申请仲裁，请求仲裁委员会依法裁决支持申请人请求被申请人 B、C公司支付结欠工程款及承担违约责任、D 地产公司承担补充支付责任。

被申请人 B 公司提出反请求，确认 A 建设公司与被申请人 B公司签署的《建设工程施工合同》无效、支付 B 公司维修地下铝缆费用及要求 A 建设公司将地下铝缆依照设计图纸和竣工图的要求全部更换为铜缆。

## 争议焦点

一、案涉两份《建设工程施工合同》的主体不同，2011年8月29日签订的《建设工程施工合同》主体为发包方 B 公司、D地产公司，承包方 A 建设公司；2013年4月15日签订的《建设工程施工合同》主体为发包方 B 公司，承包方 A 建设公司。

对于两份合同因主体不同，能否并案审理。

二、如并案审理，因2013年4月15日签订的《建设工程施工合同》主体为发包方 B 公司，并没有 D 地产公司，将 D 地产公司列为被申请人是否程序错误。

三、在两份《建设工程施工合同》当中均没有 C 公司这一主体，能否将 C 公司列为被申请人进行仲裁审理。

四、案涉两份《建设工程施工合同》是否有效。

五、申请人 A 建设公司的仲裁请求事项是否应当得到支持，其要求按照中国人民银行同期贷款利率上浮30%计算逾期付款利息是否有法律依据。

六、被申请人 B 公司要求 A 建设公司承担维修地下铝揽费用21.38万元是否成立，是否应当支持。

七、被申请人 B 公司要求 A 建设公司将地下铝揽全部更换为铜缆的请求是否成立，是否应当支持。

## 裁决结果

仲裁庭阐述意见：根据申请人 A 建设公司与被申请人 B 公司提交的证据和庭审中双方陈述、质证、辩论、对仲裁庭询问的回答，就本案相关问题及申请人 A 建设公司的仲裁请求、被申请人B 公司的仲裁反请求，仲裁庭发表如下意见：

一、申请人 A 建设公司请求被申请人 C 公司承担工程款支付责任问题。

本庭已于2021年3月15日出具仲裁决定书[（2020）巴仲决字第（0001）号]予以说明（备注：依据《中华人民共和国仲裁法》第十六条、《巴彦淖尔仲裁委员会仲裁规则》第六条、第八条、第十条第一、三、五项之规定，决定驳回申请人内蒙古A 建设工程有限责任公司对内蒙古 C 投资有限公司的仲裁申请，后续庭审内蒙古 C 投资有限公司无需参加，申请人内蒙古A 建设工程有限责任公司认为内蒙古 C 投资有限公司对请求裁决的建设工程款及违约金应承担共同支付责任的主张，可通过其他途径解决）。

二、被申请人 B 公司提出的本会不具有管辖权、不应当将 D地产公司列为被申请人问题。

（一）本案涉及两份建设工程施工合同，均约定发生争议由巴彦淖尔仲裁委员会仲裁的意思表示及条款内容，且被申请人B 公司就管辖问题向巴彦淖尔市中级人民法院、呼和浩特市中级人民法院均提出过异议诉讼，均被驳回。被申请人 B 公司提出的本会不具有管辖权的意见本庭不予支持。

（二）案涉两份建设工程施工合同，2011年8月29日的《建设工程承包合同》，主体为申请人 A 建设公司、被申请人B 公司、被申请人 D 地产公司，而2013年4月15日的《建设工程施工合同》主体为申请人 A 建设公司、被申请人 B 公司；

被申请人 D 地产公司确实并非2013年4月15日《建设工程施工合同》主体，但本案申请人 A 建设公司、被申请人 B 公司与两份建设工程施工合同的履行、预付、结算均分不开，具有关联性，为了便于查清案件事实，根据《巴彦淖尔仲裁委员会仲裁规则》第十四条六项之规定可以一案受理。并不违反本会程序，被申请人 B 公司的意见，本庭不予支持。

三、关于本案建设工程施工合同的效力问题。

申请人A 建设公司与被申请人 B 公司分别于2011年8月29日、2013年4月15日签订的《建设工程施工合同》，系双方当事人真实意思表示，且申请人 A 建设公司通过招投标程序中标后签订，程序合法，内容不违反国家法律法规的强制性规定，合法有效。被申请人 B 公司认为申请人 A 建设公司是以贿赂手段取得中标，并签订的案涉承包合同，应当认定为无效，但未提供足够的证据予以证明，本庭不予支持。

四、被申请人 D 地产公司是否应当承担补充支付申请人 A 建设公司工程款问题。

被申请人 D 地产公司虽为2011年8月29日签订的《建设工程施工合同》发包方主体，但其实质并未出资、投资或参与建设，与被申请人 B 公司之间是合作销售部分房产的代理关系，有被申请人 D 地产公司的陈述、申请人 A 建设公司提供的证据、被申请人 B 公司的答辩及举证均可予以佐证，申请人 A 建设公司的该部分主张不能成立，本庭不予支持。

五、申请人 A 建设公司要求被申请人 B 公司支付工程款6895863.33元及主张违约金计算标准、计算时间的问题。

（一）案涉两份施工合同，2011年8月29日签订的《建设工程施工合同》，于2013年10月18日竣工验收备案了2#、12#楼，2015年9月23日竣工验收备案了4#、5#、6#、11#楼；

2013年4月15日签订的《建设工程施工合同》，于2017年5月3日竣工验收备案。工程完工后，被申请人 B 公司支付过申请人 A 建设公司部分工程款，经双方于2015年、2016年对账，被申请人 B 公司结欠申请人 A 建设公司工程款8215761.73元及被申请人 B 公司2018年出具会议纪要认可结欠申请人 A 建设公司工程款6895863.33元，此后再未支付。申请人 A 建设公司请求被申请人 B 公司支付6895863.33元工程款本庭予以支持；

（二）根据双方签订的两份《建设工程施工合同》约定的竣工结算条款，工程竣工验收报告经发包人认可后28天内，承包人向发包人递交竣工结算报告及完整的竣工结算资料，双方按照协议书约定的合同价款及专用条款约定的合同价款调整内容，进行工程竣工结算。申请人 A 建设公司未向本庭提供其给被申请人 B 公司提交过工程结算报告的证据，双方在2015年6月10日、2016年9月21日进行过对账，但两次对账均明确“因为有些工程及工作还在进行中，应付及欠付随时会有一些变化”，2018年4月18日被申请人 B 公司以会议纪要的形式最终确认欠付申请人 A 建设公司工程款6895863.33元，申请人A 建设公司对此也予以认可，故被申请人 B 公司应从2018年4月18日起承担违约责任，违约责任应以银行利息的形式予以体现。为此本庭认为应以结欠工程款6895863.33元基数，从2018年4月19日计算至2020年8月19日，按照中国人民银行同期同类一至五年期贷款基准利率4.75%计算利息；从2020年8月20日起至清款之日止，按照同期全国银行间同业拆借中心公布的一年期贷款市场报价利率3.85%计算利息。申请人A 建设公司请求的按照中国人民银行同期同类贷款利率上浮30%计算违约金，无约定和法律依据，本庭不予支持。

六、被申请人 B 公司请求申请人 A 建设公司支付维修地下铝缆费用及依照设计图纸和竣工图的要求全部更换为铜缆的问题。

被申请人 B 公司的该两部分反请求，未向本庭提供证据。

（一）对于修复地下铝缆费用的问题，被申请人 B 公司陈述相应的账目被审计部门调走，无法提供，并提交了2021年3月29日审计交接清单，该案本会于2020年9月14日受理，于2020年9月25日邮寄送达了限期答辩、举证文书，被申请人应当在2020年10月11日之前提交证据，被申请人 B 公司在举证期限内，审计部门尚未调走其公司财务账目，被申请人 B公司应当对其拒不提供证据承担举证不能的后果，且其对该笔费用也未向本庭提出鉴定申请；（二）对于依照设计图纸和竣工图的要求更换为铜缆的问题，根据双方的陈述、答辩、举证、质证，工程地下铜缆更换为铝缆的事实存在，根据申请人 A 建设公司提供的被申请人 B 公司委托第三方 XXXX 工程造价咨询有限责任公司审价报告显示，被申请人 B 公司委托审价的也是铝缆，说明即使是铜缆更换成铝缆，被申请人 B 公司亦是明知和同意的。对前述两部分反请求，本庭不予支持。

七、仲裁费用的承担问题。

（一）鉴于本请求申请人 A 建设公司的仲裁请求并未全部得到支持，故本案本请求仲裁费49741.68元按申请人 A 建设公司仲裁请求被支持的情况，仲裁庭酌定由被申请人 B 公司承担48241.32元，由申请人 A 建设公司承担1500.36元。

（二）被申请人 B 公司的仲裁反请求全部未得到支持，故本案反请求仲裁费4457元全部由被申请人 B 公司承担。

裁决结果：

一、申请人 A 建设公司与被申请人 B 公司、D 地产公司2011年8月29日签订的《建设工程施工合同》合法、有效；申请人A 建设公司与被申请人 B 公司2013年4月15日签订的《建设工程施工合同》合法、有效；

二、被申请人 B 公司支付申请人 A 建设公司工程款6895863.33元及违约金，违约金参照中国人民银行同期同类贷款利率计算，即以6895863.33元为基数，从2018年4月19日计算至2020年8月19日，按照中国人民银行同期同类一至五年期贷款基准利率4.75%计算为763693.25元（6895863.33元×0.0475÷365天×851天），从2020年8月20日起按照同期全国银行间同业拆借中心公布的一年期贷款市场报价利率3.85%计算违约金至清款之日止；

三、驳回申请人 A 建设公司的其他仲裁请求；

四、驳回被申请人 B 公司对申请人 A 建设公司的仲裁反请求。

本案本请求仲裁费49741.68元，申请人 A 建设公司已预交，由被申请人 B 公司负担48241.32元，申请人 A 建设公司负担1500.36元；反请求仲裁费4457元，由反请求申请人 B 公司负担。

被申请人 B 公司应将上述应付款项在本裁决书作出之日起30日内支付给申请人 A 建设公司。逾期，则参照《中华人民共和国民事诉讼法》第二百五十三条的规定支付迟延履行金。

本裁决为终局裁决，自作出之日起发生法律效力。

## 相关法律法规解读

一、《中华人民共和国仲裁法》第十六条仲裁协议包括合同中订立的仲裁条款和以其他书面方式在纠纷发生前或者纠纷发生后达成的请求仲裁的协议。

仲裁协议应当具有下列内容：

（一）请求仲裁的意思表示；

（二）仲裁事项；

（三）选定的仲裁委员会。

本条是关于有效仲裁协议的形式要件和实质要件的规定，仲裁法规定有效的仲裁协议必须采用书面形式，口头形式的无效。

仲裁协议有效的形式：其一，在合同中订立有仲裁条款；其二，在纠纷发生前或者纠纷发生后达成的请求通过仲裁解决的协议。另外，在某一些民商事活动中，通过信函、电报、电传或其他书面材料，共同约定将已发生或者将来可能发生的有关争议提交仲裁的意思表示，也是成为仲裁协议。

仲裁协议实质意义：

（一）请求仲裁的意思表示。仲裁协议必须是双方当事人要将争议提交仲裁的共同的、真实的意思表示。任何单方的或不真实的意思表示都属无效。

（二）仲裁事项。可协议提交仲裁的事项仅限于本法第二条规定的范围，在此范围内，仲裁协议既可将已经发生的争议提交仲裁，也可事先约定将来可能发生的争议提交仲裁。但不允许将不特定的将来的争议约定提交仲裁。

（三）选定的仲裁委员会。仲裁不实行级别管辖和地域管辖，当事人可以约定将其争议提交国内任何一个当事人信任的或处理争议比较便利的仲裁委员会。

二、《巴彦淖尔仲裁委员会仲裁规则》第六条仲裁协议（一）仲裁协议是指当事人同意将已经发生或者可能发生的合同纠纷或者其他财产权益纠纷提交仲裁的合意。包括当事人在合同中订立的仲裁条款或者在纠纷发生前后达成的将纠纷提交仲裁的书面协议。

（二）书面形式包括合同书、信件、庭审笔录、 传真、电报、电传、电子邮件、电子数据等能够有形表现所载内容的形式。

（三）在仲裁申请书和答辩书的交换中，一方当事人声称有仲裁协议而另一方当事人不作否认表示的，视为存在书面仲裁协议。

（四）当事人在合同中援引其他载有仲裁条款的书面文件解决有关的争议，且该文件构成合同的必要组成部分，视为存在书面仲裁协议。

第八条仲裁协议应当具有下列内容（一）请求仲裁的意思表示；

（二）仲裁事项；

（三）选择本会。

第十条对仲裁管辖的异议（一）当事人对仲裁协议的存在、效力或者案件的管辖权有异议的，应当在首次开庭前以书面形式提出;约定书面审理的，应当在首次答辩期限届满前以书面形式提出。

当事人未依照上述规定提出异议的，视为承认本会对仲裁案件有管辖权。

（五）本会或者本会授权的仲裁庭作出无管辖权决定的，应当驳回仲裁申请;作出有管辖权决定的，仲裁程序继续进行。

第十四条受理（六）涉及两份或者两份以上合同的争议，当事人可以在单个仲裁案件中合并提出仲裁申请，但应当同时符合下列条件：

1.各份合同涉及的当事人相同;2.各份合同涉及法律性质相同或具有关联性;3.争议源于同一交易或者互不可分的同一系列交易;4.各份合同的仲裁协议内容相同或者彼此兼容。

对于符合上述条件的合同争议，本会可以决定按一案受理。

第十六条反请求（一）被申请人有权依据同一仲裁协议提出反请求。反请求的当事人限于仲裁请求的当事人，对方同意的除外。

（二）被申请人提出反请求，应当在答辩期内以书面形式提交本会。逾期提交的，仲裁庭组成前由本会决定是否受理;仲裁庭组成后由仲裁庭决定是否受理。

（三）本会或者仲裁庭决定是否受理逾期提出的反请求时，应当考虑反请求与本请求合并审理的必要性、逾期提出的时间、是否会造成程序的不必要拖延以及其他有关因素。

（四）反请求的受理及答辩适用本章有关规定。

三、《巴彦淖尔仲裁委员会证据规定》第二十四条当事人申请鉴定，应当在仲裁庭指定期间内提出，并向鉴定人预交鉴定费用。逾期不提出申请或者不预交鉴定费用的，视为放弃申请。

对需要鉴定的待证事实负有举证责任的当事人，在仲裁庭指定期间内无正当理由不提出鉴定申请或者不预交鉴定费用，或者拒不提供相关材料，致使待证事实无法查明的，应当承担举证不能的法律后果。

四、原《中华人民共和国合同法》第四十四条依法成立的合同，自成立时生效。

法律、行政法规规定应当办理批准、登记等手续生效的，依照其规定。

第六十条当事人应当按照约定全面履行自己的义务。

当事人应当遵循诚实信用原则，根据合同的性质、目的和交易习惯履行通知、协助、保密等义务。

第一百零七条当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。

第一百一十四条当事人可以约定一方违约时应当根据违约情况向对方支付一定数额的违约金，也可以约定因违约产生的损失赔偿额的计算方法。

约定的违约金低于造成的损失的，当事人可以请求人民法院或者仲裁机构予以增加；约定的违约金过分高于造成的损失的，当事人可以请求人民法院或者仲裁机构予以适当减少。

第二百六十九条建设工程合同是承包人进行工程建设，发包人支付价款的合同。

建设工程合同包括工程勘察、设计、施工合同。

## 结语和建议

该案件涉及两份不一致主体的工程施工合同，在施工、履行、结算过程两份合同工程量、工程款难以区分，不能就两份合同单独进行裁决，为此，在程序方面为被申请人寻求拖延留有了空间。

现实生活中，涉及第三人的案件较多，需要在仲裁法修订或仲裁规则制定过程中对第三人选定仲裁员问题、仲裁地位、承担的权利义务等问题进一步进行明确。
