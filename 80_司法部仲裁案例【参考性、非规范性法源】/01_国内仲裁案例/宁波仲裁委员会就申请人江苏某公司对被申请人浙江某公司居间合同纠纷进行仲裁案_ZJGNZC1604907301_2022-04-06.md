# 宁波仲裁委员会就申请人江苏某公司对被申请人浙江某公司居间合同纠纷进行仲裁案

宁波仲裁委员会就申请人江苏某公司对被申请人浙江某公司居间合同纠纷进行仲裁案

## 案情简介

2015年10月15日，上海 C 公司委托浙江 B 公司甄选推荐某开发项目合格材料供应商及施工承包商。

2015年12月11日，浙江 B 公司与江苏 A 公司签订《项目材料供应商战略企业甄选协议书》一份,约定，一、浙江 B 公司为上海 C 公司指定的全面战略合作单位,具体按照上海 C 公司的委托范围对外进行某开发项目建设采购材料的发包。二、江苏A 公司按照浙江 B 公司要求指定品种材料等进行变电设备供应商初选。三、在定向确定战略供应商后，江苏 A 公司提供企业的资料备案后进行定向议标。四、参加定向议标的每家企业缴纳保证金100 000元，投标资料费3 000元，开标后中标企业的100 000元投标保证金转为战略合作入围费，在材料供应过程中逐步退回。五、每家企业向浙江 B 公司缴纳战略供应合作入围费30 000元,在中标后并签订正式合同后,该入围费转为浙江 B 公司的居间费。

2015年11月30日，江苏 A 公司以银行转账的方式支付浙江B 公司50 000元，用途为投标保证金，浙江 B 公司于同日向江苏A 公司出具收款收据一份，用途为材料招投标入围费；

2015年12月14日，江苏 A 公司再次以银行转账的方式支付浙江B 公司115 000元，用途为投标保证金，浙江 B 公司在当日向江苏 A 公司出具收款收据一份，载明用途为材料招投标入围费。

2015年12月25日，江苏 A 公司作为与镇江 D 公司、陕西 E公司等五家公司的代表与浙江 B 公司签订《项目材料供应商战略企业甄选协议书》补充协议书，约定，一、10万元投标保证金的处置方案：1、原协议第四项中载明的要求入围企业提前缴纳投标保证金共50万元，该款现由浙江 B 公司代江苏 A公司先行垫付给上海 C 公司。当江苏 A 公司在某开发项目中获得变配电、材料设备的招标文件和材料清单后，于投标时向浙江B 公司支付所垫付费用。二、原协议第五项3万元居间管理费的处置方案：江苏 A 公司已向浙江 B 公司缴纳的3万元居间管理费，浙江 B 公司已开具收款收据，此款的退还应在江苏 A公司签订商务合同后，从应返还给浙江 B 公司的合同额增值部分中扣减给江苏 A 公司。三、3 000元资料费的处置方案：江苏A 公司已交给浙江 B 公司的资料费，作为江苏 A 公司从浙江B 公司获取某开发项目相关资料文件的直接费用，不予退还。

2015年12月16日，江苏 A 公司在《项目战略合作协议书（材料）》上签章后，上海 C 公司于2016年2月3日在该协议上签章。该协议约定，三、资格入围方式：2、江苏 A 公司经过甄选被入选成为某开发项目战略合格供应商后，需向上海C 公司缴纳相应的入围费。四、双方的权利义务：2、江苏 A公司接到上海 C 公司的邀请、邀标（通知）函后，应在规定的时间内完成各项投标工作，中标后应立即与上海 C 公司及该公司指定的单位订立供货协议/合同。

2016年2月1日，浙江 B 公司以银行转账的方式向上海 C公司支付103 000元，次日，上海 C 公司出具收款收据一份，载明缴款单位江苏 A 公司，金额100 000元，收款事由保证金（入围费）。

之后，上海 C 公司未通知江苏 A 公司参加投标，亦未同江苏A 公司就某开发项目签订材料采购供应合同。至2018年6月29日，江苏A 公司向浙江 B 公司催促签订某开发项目建设工程材料采购供应合同，浙江 B 公司表示因为未通过许可审批，该项目无法实施。

2019年11月5日，江苏 A 公司向宁波仲裁委提起仲裁，请求：1、裁决解除江苏 A 公司与浙江 B 公司之间的《项目材料供应商战略企业甄选协议书》及补充协议；2、裁决浙江 B 公司返还江苏 A 公司居间管理费150 000元及资料费15 000元，并自申请仲裁之日起按年利率6%赔偿利息损失至实际付清日止。

浙江B 公司抗辩称，已经将江苏 A 公司支付款项中的100000元作为保证金支付给上海 C 公司，对该部分款项同意从上海C 公司取回后返还给江苏 A 公司；其余款项属于材料费或居间报酬，江苏 A 公司已经同上海 C 公司签订合同，不同意退还。

## 争议焦点

浙江B 公司的居间报酬请求权是否成立？

## 裁决结果

仲裁庭经审理后认定，在合同履行过程中，江苏 A 公司与浙江B 公司对于案涉165 000元款项的性质意见不一，但是根据《项目材料供应商战略企业甄选协议书》及补充协议，浙江 B公司开具的收款收据内容，其中150 000元属于居间报酬，15000元属于材料费。依据浙江 B 公司的居间服务，江苏 A 公司与上海C 公司在2015年12月16日至2016年2月3日期间，江苏A 公司与上海 C 公司签订了《项目战略合作协议书（材料）》，但是至今止未按合同法规定及项目材料供应商战略企业甄选协议书》补充协议约定，进行招投标并签订材料采购供应合同，因此浙江 B 公司并未促成江苏 A 公司与上海 C 公司订立合同，无权要求支付居间报酬，因此应当返还150 000元居间报酬，至于支付给上海 C 公司的100 000元入围费（保证金）

由浙江B 公司处理。裁决：

一、浙江 B 公司在裁决书送达之日起七日内返还江苏 A 公司居间费150 000元。

二、浙江 B 公司赔偿江苏 A 公司自2019年11月5日起至实际付清日止以150 000元为基数按年利率6%计算的利息损失。

三、驳回江苏A 公司的其他仲裁请求。

## 相关法律法规解读

1、《中华人民共和国合同法》第四百二十四条居间合同是居间人向委托人报告订立合同的机会或提供订立合同的媒介服务，委托人支付报酬的合同。

2、《中华人民共和国合同法》第四百二十六条居间人促成合同成立的，委托人应当按照约定支付报酬。对居间人的报酬没有约定或者约定不明确，依照本法第六十一条的规定仍不能确定的，根据居间人的劳务合理确定。因居间人提供订立合同的媒介服务而促成合同成立的，由该合同的当事人平均负担居间人的报酬。

居间人促成合同成立的，居间活动的费用，由居间人负担。

3、《中华人民共和国合同法》第四百二十七条居间人未促成合同成立的，不得要求支付报酬，但可以要求委托人支付从事居间活动支出的费用。

## 结语和建议

结合案情分析，江苏 A 公司与浙江 B 公司之间酿成纠纷的根本原因在于江苏 A 公司与上海 C 公司之间未能订立材料采购供应合同，但是江苏 A 公司与浙江 B 公司之间订立、履行合同不够明确、规范也是重要原因之一。因此，当事人在订立合同时，应当依照合同的类型性质，对标的、数量、质量、价款或报酬、履行期限地点和方式、违约责任、解决争议方法等内容作出明确约定。在履行合同时，应当根据约定全面、严格进行履行，如发生争议，应及时协商，统一意见，消除分歧。
