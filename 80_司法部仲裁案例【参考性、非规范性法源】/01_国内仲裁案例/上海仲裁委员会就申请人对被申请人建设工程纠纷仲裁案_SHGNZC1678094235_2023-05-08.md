# 上海仲裁委员会就申请人对被申请人建设工程纠纷仲裁案

上海仲裁委员会就申请人对被申请人建设工程纠纷仲裁案

## 案情简介

2015年10月10日，A 与B 组成联合体，与业主 C 签订《EPC 总承包合同》，约定由 A 作为BRT（Bus Rapid Transit）

工程采购、施工总承包方。合同同时约定工程款项为人民币1,073,023,575元（以下所涉货币币种均为人民币），工程进度款支付方式为根据施工进度当年支付已完工程量的60%、完工第二年竣工验收决算后支付20%、完工第三年支付20%。

2016年5月25日，A 与D 签订《工程分包合同》，约定将案涉工程分包给 D。合同约定：1、合同暂定价为15,972,400元，工程进度款由 A 在收到业主 C 实际支付并扣除相关费用后20日内支付给 D，工程款支付至合同造价的60%时，不再按进度付款，其余部分工程款待工程完工且竣工验收移交、内业资料合格移交、办理竣工决算并在业主 C 拨付工程款30日后支付至合同结算款的80%，在完工第二年且业主拨付工程款30日后支付至结算款的95%，剩余5%在保修期满后支付，保修期为自业主 C 工程验收合格之日起2年。2、D 应当在开工前提交金额为合同总价10%的履约保证金，履约保证金之期限至工程竣工结算完成；如果 D 无法提交，则由 A 在支付工程进度款时扣除并在 D 累计已完成工作量达到合同价50%时扣完，在工程结算后退还予 D。3、A 在工程尾款中留存工程合同价款的1%作为工程档案资料归档保证金，待 D 将全部工程档案资料按规定要求经 A、监理、业主 C、档案馆验收并移交后返还。

《工程分包合同》签订后，D 遂进场施工。

2016年10月14日，A 又与 D 签订《工程分包合同补充协议》，约定在《工程分包合同》约定之工程范围的基础上增加工程，合同金额为2,450,880元，其他条款参照《工程分包合同》不变。

案涉工程的结算价为18,980,000元；A 已向 D 支付工程款11,850,000元。

截至2018年11月23日，业主 C 已向A 支付工程款537,082,551元。

D 于2018年11月1日向仲裁委提出仲裁请求、财产保全申请后撤回申请而产生了仲裁费46,095元、财产保全费5,000元、保全担保费13,000元。D 又于2018年12月20日向仲裁委提出仲裁请求、财产保全申请后产生了律师费60,000元，仲裁费86,683元、财产保全费5,000元、保全担保费7,600元。

D 认为：D 已完成施工建设，A 应当按照合同约定支付工程款。经D 与A 核算确认，案涉工程的工程款总计为18,980,000元，A 仅支付工程款11,850,000元，尚欠付工程款7,130,000元。

因此，D 主张：1、A 支付D 尚欠的工程款本金7,130,000元（最终以仲裁过程中鉴定机构出具的造价鉴定报告所确认的数额为准）；2、A 支付D 自2017年7月16日起至2018年12月19日止期间结算款利息299,990.11元，支付2018年12月20日起至实际履行之日止期间的利息（以7,130,000元为本金，按照中国人民银行同期贷款利率算）；3、A 支付 D 因追索债权产生的律师费损失共计60,000元；4、A 支付D 因2018年11月1日提起仲裁又撤回仲裁发生的损失，包括仲裁费46,095元、财产保全费5,000元，保全担保费13,000元，共计64,095元；5、A 支付本案的仲裁费、财产保全费5,000元、保全担保费7,600元。

A 认为：1、BRT 工程至今未通过竣工验收。2、D 未向A 递交结算资料，双方尚未办理完工结算。3、A 未拖欠 D 的工程进度款。按照合同约定，因 D 并未向 A 提交履约保证金，A 支付的进度款应仅为合同价的50%。但是，A 实际支付的工程进度款为11,850,000元，已达合同价（18,423,280元，含补充协议价款）的64.32%，远超过合同约定。截至目前，A 共收到业主C 工程进度款537,082,551元，仅为合同价的50%，却已向D 支付了64.32%工程款，由此也说明 A 不但严格按合同约定履行，还垫资向 D 超付了工程款。4、D 现无权要求 A 支付剩余工程款。

综上所述，D 认为 A 已经按合同约定履行了付款义务，剩余工程款因合同约定的付款条件并不具备，因此请求仲裁庭驳回D 的全部仲裁请求。

## 争议焦点

## 裁决结果

仲裁庭依据《仲裁规则》第五十三条的规定，裁决：

1、A 向D 偿付律师费30,000元。2、A 向D 偿付财产保全费2,500元、保全担保费3,800元。3、本案仲裁费双方各半承担。4、对D 其他仲裁请求不予支持。

就上述争议焦点，仲裁庭具体分析如下：

仲裁庭认为，根据《工程分包合同》，A 支付至合同结算价80%的前提条件为工程完工且竣工验收移交，内业资料合格移交、办理竣工决算且业主 C 拨付工程款30日后，而双方对于“竣工验收、竣工决算”系针对案涉工程还是 BRT 工程，以及“业主方拨付工程款”的理解产生了争议。根据《中华人民共和国合同法》第一百二十五条的规定，当事人对于合同条款的理解有争议的，应当按照合同所使用的词句、合同的条款、合同目的、交易习惯以及诚实信用原则，确定该条款的真实意思。

因此，对于前述付款条件的具体理解应当结合合同上下文、双方订立合同的目的等多项因素考虑。

对于“竣工验收、竣工决算”是指 BRT 工程还是案涉工程，在D 与A 对案涉工程是否可以进行竣工验收产生争议的情况下，D 未能举证证明双方对于案涉工程的竣工验收有过约定、亦未证明针对案涉工程的完工可以进行竣工验收。而且对照案涉工程与BRT 工程的付款节点，根据《EPC 总承包合同》的约定，BRT 工程的工程款支付方式为按照施工进度支付60%，待 BRT工程竣工验收决算后支付20%，待BRT 工程完工第三年支付20%；而根据《工程分包合同》的约定，案涉工程的工程款支付方式为按照施工进度支付60%，待工程完工且竣工验收移交、内业资料合格移交、办理竣工决算并在业主方拨付工程款30日后支付20%，在完工第二年且在业主方拨付工程款30日后支付15%，保修期满后支付5%。由此可见，案涉工程的工程款支付方式大致与 BRT 工程的工程款支付方式相对应，A 与D 约定案涉工程的工程款支付时间应当是在充分考虑到 BRT 工程的工程款支付时间之基础上，因此仲裁庭认为《工程分包合同》中约定的工程款支付条件中的“竣工验收、竣工决算”系指BRT 工程的竣工验收及决算。鉴于 D 未提供 BRT 工程的竣工验收证明，A 又称BRT 工程的竣工验收未完成，因此，仲裁庭认为，A 与业主 C 尚未完成 BRT 工程的竣工验收。

对于“业主拨付工程款”的理解，仲裁庭认为，总包单位与分包单位将建设单位付款约定为分包工程款的支付前提，通常系出于缓解总包单位的资金压力、让分包单位与总包单位共同分担施工过程中的风险之考虑，因此 A 与D 将“业主拨付工程款”约定为支付工程款的前提条件之本意应当是指在业主 C 按照《EPC 总承包合同》约定的进度比例向 A 支付足额工程款后，A 再向D 支付相应分包工程款。否则，若如 D 主张，只要业主C 付过工程款，即视为条件满足，将无法达到双方订立该条款的目的。加之，建设单位按照总包合同的约定向总包单位支付足额工程款、总包单位继而按照分包合同的约定向分包合同支付分包工程款，该种操作亦符合建设工程行业中的通常做法。

因此，仲裁庭认为，《工程分包合同》中约定的案涉工程工程款支付条件中的“业主方拨付工程款”应当是指 A 在按照《EPC 总承包合同》的约定收到业主 C 支付的相应 BRT 工程款项后、再按照《工程分包合同》的约定向 D 支付案涉工程的工程款。关于 A 主张的业主未支付20%BRT 工程结算款、其已经积极履行了向业主 C 主张工程款的义务，虽然 D 不予认可，但是根据D 提供的证据《XXX 工程施工结算单》，D 与A 最早系于2018年12月1日完成案涉工程的结算，考虑到案涉工程作为BRT 工程的一部分，A 与D 完成案涉工程的结算系业主 C 与A 完成BRT 工程结算的基础，因此，仲裁庭认为 A 所称的业主C 与A 尚未完成 BRT 工程的结算具有可信性。

综上，仲裁庭认为因无切实证据证明 BRT 工程已竣工验收移交、业主 C 已向 A 拨付工程结算款，故 D 主张的 A 支付至《工程分包合同》结算价80%的付款条件并未成就，支付至《工程分包合同》结算价95%、支付剩余5%工程款的条件亦未成就，仲裁庭不予支持关于 D 支付案涉工程剩余工程款的请求。

## 相关法律法规解读

关于背靠背条款：《建设工程施工专业分包合同（示范文本》（GF-2003-0213）通用条款第19.5款规定：分包合同价款与总包合同相应部分价款无任何连带关系。根据《关于2014版<建设工程专业分包合同（示范文本）>的起草说明》规定：以业主支付为前提的工程款支付问题是困扰总包与分包企业合同支付的主要难题。2014版分包合同没有将业主支付设置为承包人向分包人支付分包合同价款的条件，保持了分包工程价款结算和支付的独立性。但《北京市高级人民法院关于审理建设工程施工合同纠纷案件若干疑难问题的解答》（京高法发〔2012〕245号）第22条、分包合同中约定总包人收到发包人支付工程款后再向分包人支付的条款的效力如何认定？据此给出的答复是：分包合同中约定待总包人与发包人进行结算且发包人支付工程款后，总包人再向分包人支付工程款的，该约定有效。

本案中，仲裁庭虽援引《中华人民共和国合同法》第一百二十五条的规定，但根据仲裁庭对于“竣工验收、竣工决算”是指BRT 工程还是案涉工程等认定内容，正是考虑到建设工程纠纷案件中常见的“背靠背条款”问题，案涉工程的工程款支付方式大致与 BRT 工程的工程款支付方式相对应；总包单位与分包单位将建设单位付款约定为分包工程款的支付前提，通常系出于缓解总包单位的资金压力、让分包单位与总包单位共同分担施工过程中的风险之考虑。由此，仲裁庭综合分析后认为，A 所称的业主 C 与A 尚未完成 BRT 工程的结算具有可信性。本案中，仲裁庭认为因无切实证据证明 BRT 工程已竣工验收移交、业主C 已向 A 拨付工程结算款，故 D 主张的 A 支付至《工程分包合同》结算价80%的付款条件并未成就，支付至《工程分包合同》结算价95%、支付剩余5%工程款的条件亦未成就，进而仲裁庭不予支持关于 D 支付案涉工程剩余工程款等请求。

## 结语和建议

商事仲裁强调尊重当事人的自由意志，在“背靠背条款”未违反法律、行政法规强制性规定的情况下，应认可其效力。商事合同条款是否公平，也应当结合具体行业情况来判断。一般而言，分包人接受“背靠背”付款是承接分包工程的前提条件之一，且该付款约定也符合工程行业的惯例。因此，“背靠背条款”使得承包人获得延期付款的时间利益，于分包人而言，系双方对付款时间的安排，并无不公。

然而，虽“背靠背条款”通常认定有效，但对于承包人援引该条款的抗辩付款，应当根据个案的具体情况，结合“公平合理”等原则综合处理为妥。
