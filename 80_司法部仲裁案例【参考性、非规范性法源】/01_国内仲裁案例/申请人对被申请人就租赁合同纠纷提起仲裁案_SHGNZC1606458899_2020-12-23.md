# 申请人对被申请人就租赁合同纠纷提起仲裁案

申请人对被申请人就租赁合同纠纷提起仲裁案

## 案情简介

2018年6月4日，P 公司经产权人授权与 X 公司签订《厂房租赁合同》，约定将系争厂房租赁给 X 公司用于生产办公，其中业主留用一间，租赁期自2018年7月1日至2021年6月30日，年租金及物业费分别为人民币150,000元及12,000元，每半年一付。同时约定，P 公司同意首次支付租金及物业费时间放宽至合同签订生效后两个月内，之后提前一个月支付，如延迟超过10天的，P 公司有权收回房屋，并要求对方承担损失。同年6月30日，双方及案外人签署交接清单称，案外人（即原租赁方）根据租赁合同约定，将系争建筑全部移交给 X公司；整栋建筑使用权归 X 公司所有（合同约定 P 公司无偿使用的房间和案外人无偿使用的房间除外）、遗留租户由 X 公司管理、遗留租户的房租押金物业管理费等所有费用由 X 公司收取、垃圾清运费由 X 公司承担，等等。同年8月9日，X 公司收到以其为单位名称、案涉租赁房屋为单位地址的环保检查工作表，认为企业没有环评而要待电箱更换好后封电查封。之后，P 公司以 X 公司实际使用租赁房屋，但未曾支付任何费用为由提起仲裁申请。要求解除涉案《厂房租赁合同》、X 公司支付半年租金及物业费81,000元、及赔偿房屋空置期损失，计三个月租金及物业费40,500元。X 公司对此抗辩认为，由于系争合同所涉及的房屋有他人在使用，P 公司并未向 X 公司交付全部的房屋，X 公司没有也根本无法按合同整体履行。因租赁房屋的环评通不过，双方当事人因此协商一致解除了 X 公司实际使用部分的房屋租赁关系，并已结清涉及的全部费用，故双方不应当再存在纠纷。

## 争议焦点

第一，系争合同所涉之租赁房屋是否已完会按约交付使用，即合同是否已经成立生效。

第二，P 公司要求解除合同是否应当予以支持。

第三，X 公司是否应当支付拖欠的租金及物业费。

第四，X 公司是否应当赔偿房屋空置期损失。

## 裁决结果

对第一个争议焦点，仲裁庭认为 X 公司以三方签署的交接书为由认为交付不完全，仅是对文字的推断，该理由并不成立，故合同合法有效，且 P 公司已完全交付房屋。对第二个争议焦点，合同约定迟付租金超过10天以上，则 P 公司有权直接收回房屋，并要求对方赔偿损失，此应当理解为附有解除条件的合同。现在解除条件已经成就，P 公司有权解除合同，但应当通知对方。现没有证据证明 P 公司已依规履行了通知程序，故虽已实际收回房屋，仍认为解除合同之时应当为裁决生效之日。

对第三个争议焦点，合同终止并不影响合同的结算或清理，故X 公司应当支付拖欠的费用。对第四个争议焦点，因系争合同中并未有关于空置期损失的约定，且 P 公司实际收回租赁房屋使用权的时间也无证据可证明，故该请求不予支持。

## 相关法律法规解读

1、《中华人民共和国合同法》第九十三条第二款，当事人可以约定一方解除合同的条件。解除合同的条件成就时，解除权人可以解除合同。

2、《中华人民共和国合同法》第九十六条第一款，当事人一方依照本法第九十三条第二款、第九十四条的规定主张解除合同的，应当通知对方。合同自通知到达对方时解除。对方有异议的，可以请求人民法院或者仲裁机构确认解除合同的效力。

## 结语和建议

房屋租赁合同是最为常见的民事合同之一，在民商事领域被广泛签署运用，个人的工作生活、企业的经营发展都需要以固定的住所为前提。因此，房屋租赁合同纠纷也是仲裁审理过程中最为常见的合同纠纷类型之一。签订房屋租赁合同应当注意约定条款的完备性，比如租赁部位应当清楚明确、用途明确、修缮责任明确、是否可以转租、违约责任、解除条款、损失赔偿、甚至遇到动拆迁时候的处理等问题。这样才能在发生纠纷时有约可依，也能为之后的履约行为进行指引。在履约过程中，合同各方也应当遵守诚实信用等原则，依法依约，确保合同约定得到落实。
